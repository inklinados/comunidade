# Acordo de Trabalho (template)

Modelo para qualquer projeto dentro do Inklinados. Cada projeto copia este arquivo na raiz e ajusta o que precisar. O padrão é leve de propósito. Não se somam regras por prazer.

## Dono do projeto

Todo projeto tem um dono: quem concebeu a ideia e responde pelo rumo. O dono define escopo, prioridade e o que entra em cada versão.

## Ajuda cruzada

Qualquer membro pode entrar no projeto de outro. Entra com o que já sabe e pergunta o que não sabe. Quem recebe a ajuda decide o que entra.

## Revisão

Mudança de código passa pela leitura de outra pessoa. Com poucas pessoas, revisão é conversa, não cerimônia.

O autor roda os testes da própria frente antes de pedir a revisão. Commits pequenos, uma mudança por commit, mensagem clara.

## Feito

Uma entrega está feita quando passa nos testes e quem vai colaborar entendeu o que mudou. Sem entendimento, não está pronta.

## Cadência

Cada projeto combina a própria cadência. Uma reunião curta por semana e um canal assíncrono bastam para a maioria das duplas.

## Segurança

Nada de segredo no repositório. Senha, token ou chave que apareceu no commit é tratada como vazamento.

Acesso ao servidor só para quem precisa. Quem não administra o servidor entrega código pronto e o deploy é combinado.

## Discordância

O dono do projeto decide no próprio projeto. Se sobrar atrito no coletivo, o anfitrião media. Ninguém resolve na pressão.
